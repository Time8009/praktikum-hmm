## ‼️Required
- **Operating System:** Linux (Ubuntu/Debian, Mint) or Windows 10/11 with WSL2
- **Docker Engine:** Version `24.0+` & Docker Compose `v2.0+`
- **PHP:** `^8.2` (including extensions: `pdo`, `pdo_mysql`, `mbstring`, `openssl`, `tokenizer`, `xml`, `ctype`, `json`)
- **Composer:** `^2.5`
- **Git:** Version `2.30+`
